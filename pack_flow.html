04

支撑这套流程的关键机制KEY MECHANISMS

📄

manifest.json自动流程开关

命名规则 任务名_manifest.json；记录 upload_files / publish_options / previews / 资产与环节信息。系统识别到它，自动流程才开工。

👁️

版本监控模块Linux 服务

ftptailer 实时盯 FTP 日志 → recorder 全量入库（谁上传、多大、覆盖、删除）；覆盖时自动标记 v002；同时向队列推送文件事件。

🔀

行为分配模块Linux 服务

常驻 pipeline 抓取队列事件 → FastAPI 按事件类型路由行为；耗时任务通过 Deadline API 调度农场；可读写 W 盘 / I 盘。

🤖

自动行为模块Linux 服务

按环节执行 TD 编写的检查代码（路径规范、帧率帧数等）；队列 + 农场节点消化并发耗时任务，等待结果后反馈。

🔐

权限分配模块Windows 控制端

实时管理用户与权限；新增外包商自动建 Shotgun 用户 + Linux / FTP 账户，自动生成密码，连接信息通过钉钉发送。

🔔

钉钉反馈闭环全流程

文件检查不通过 → 通知外包商 + 制片；程序报错 → 通知 TD；通过 / 发布结果 → 通知制片与外包商。所有环节结果即时触达。
